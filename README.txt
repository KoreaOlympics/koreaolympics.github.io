LA28 올림픽예선 사이트 — 게시판 (publish/) — GitHub Pages 등 공개 배포용
==========================================

이 폴더의 모든 올림픽예선 종목 페이지(ol*.html)에는 다음 두 기능이 들어 있습니다.

1) 위키 편집기
   - 각 페이지 상단 툴바의 [✎ 편집]을 누르면 본문·표를 위키백과처럼 직접 고쳐 쓸 수 있습니다.
   - [💾 저장]을 누르면 이 브라우저(localStorage)에 저장되어, 새로고침해도 유지됩니다.
   - [⬇ JSON] / [⬆ JSON]으로 편집 내용을 파일로 내보내거나 다른 기기/브라우저로 옮길 수 있습니다.
   - [＋ 게시글]로 페이지 하단 게시판에 자유롭게 글을 남길 수 있습니다.
   - [초기화]를 누르면 처음 배포된 원문으로 되돌아갑니다.

2) 쿼터 계산기
   - "체급/세부종목 및 출전권" 표의 배정 인원을 자동으로 읽어와 계산기에 채웁니다.
   - "확보(입력)" 칸에 확보(예상) 인원을 입력하면 잔여 쿼터가 자동으로 계산되고, 값은 브라우저에 저장됩니다.

파일명은 publish/ 폴더와 완전히 동일합니다 — 두 폴더는 서로 바꿔 써도 링크가 그대로 작동합니다.
index1.html은 두 폴더에 동일하게 들어 있으며 편집 기능이 없는 정적 목차 페이지입니다.

로컬에서 열어 쓰는 용도(직접 편집·기록)로 이 editor/ 폴더를 사용하세요.
외부에 공개 배포(GitHub Pages 등)할 때는 publish/ 폴더를 사용하세요 — 편집 툴바·게시판이 빠지고
쿼터 계산기만 남은 방문자용 정적 버전입니다.
