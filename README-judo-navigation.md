# 유도 탐색 구조 개편

기본 탐색은 전체 안내·14개 체급·혼성 단체의 16개입니다. 체급 페이지에서는 예선 규정·한국 선수·랭킹·2025~2026 성적·출처를 같은 순서로 탐색합니다. 칼럼·한국 선수단·선수 소개·변천 자료는 하단 알약형 메뉴로 분리했습니다.

ZIP의 16개 HTML과 css/, js/를 기존 저장소의 같은 경로에 덮어씁니다. 기존 칼럼·변천 자료·선수 소개·선수단 페이지와 기존 랭킹 데이터 파일은 유지해야 합니다. 이번 ZIP은 탐색 개편 수정 파일만 담습니다. 이전에 만든 칼럼과 자료 파일도 게시해 두어야 하단 링크가 열립니다.

기존 예선 규정·선수 소개·랭킹 기능을 유지했고 체급별 최근 성적과 IJF 선수 링크를 추가했습니다. 기존 소개의 과거 순위는 당시 기준일을 유지하며 추가한 최근 자료의 표시일과 구분합니다. 실제 사이트에는 아직 게시하지 않았습니다.
