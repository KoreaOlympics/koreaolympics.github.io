고치는 방법

  1. 표의 편집이나 문서의 [편집]을 눌러 GitHub에서 자료 파일(JSON)을 고치고 저장(Commit)한다.
  2. 저장하면 워크플로 Refresh가 기준일을 오늘로 맞추고 관련 문서를 다시 만들어 몇 분 안에 사이트에 올린다.
  3. 손대지 않아도 매일 새벽(KST) 같은 워크플로가 자동 자료를 다시 읽는다. 바로 돌리려면 워크플로 화면의 Run workflow.
